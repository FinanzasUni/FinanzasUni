# Formato estándar: carrusel de Instagram

Estructura usada consistentemente en los posts ya producidos (ver [[bloque-01-cimientos]]
y [[bloque-02-ahorro-real]]):

1. **Slide 1 — Portada/hook**: título + frase de una línea que detiene el scroll.
2. **Slide 2 — Problema o mito**: plantea la fricción o el error común.
3. **Slide 3 — Explicación/método**: pasos concretos o el "cómo".
4. **Slide 4 — Ejemplo numérico**: cifras reales en euros, casi siempre con un antes/después.
5. **Slide 5 (o 6) — CTA**: pregunta para comentarios + "guarda este post".

Cada slide individual vive como archivo HTML en `slides/pN-sN.html`, usando
`slides/_template.html` como base de diseño (fondo oscuro + dorado, coherente con
[[../marca/arquitectura-financiera]]).

Cada post incluye además:
- Hook de apertura (primera línea, usado también como texto de portada del Reel cuando aplica)
- Caption completa para Instagram
- Set de hashtags (ver lista recurrente en [[../marca/voz-y-tono]])
- Hora sugerida de publicación y semana del calendario de lanzamiento

Cuando generes un post nuevo con el agente IA ([[../tecnologia/agente-ia]]), sigue esta
misma estructura de 5 elementos para mantener consistencia visual y de copy.
