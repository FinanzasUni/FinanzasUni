Conectando con Instagram
🔗
Instagram no conectado
Sigue estos pasos para conectar tu cuenta de Instagram Business/Creator
1Ve a developers.facebook.com → Mis Apps → Nueva App → Empresa
2Añade el producto Instagram Graph API y conecta tu cuenta Business/Creator
3En "Explorador de la API Graph" genera un token con permisos:
instagram_basic · instagram_manage_comments · instagram_manage_insights
4Edita el archivo .env y añade:IG_ACCESS_TOKEN=tu_token_aqui
IG_USER_ID=tu_id_numerico_aqui
5Reinicia el servidor con npm run dev y vuelve a esta página
